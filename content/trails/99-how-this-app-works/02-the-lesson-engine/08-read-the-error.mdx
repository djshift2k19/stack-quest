  hints:
    - The translator says which name JavaScript doesn't know. Compare it with the name on line 1.

  tests:

When code crashes, you get an <Term word="error-message">error message</Term>. Stack Quest shows a plain-English explanation first and keeps the real message underneath, so you learn to read both.

Press **Run & check** and read what the translator says. Then open **"The real error message"** and see how it says the same thing in fewer words.
