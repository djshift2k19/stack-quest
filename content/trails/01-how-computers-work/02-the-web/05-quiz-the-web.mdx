  - Recall the key ideas from this module.
questions:
  - prompt: Your mobile data runs out. Which of these stop working?
    options:
      - text: Websites, WhatsApp and email, because they all travel over the internet
        correct: true
        why: Right. The web is just one kind of internet traffic, so everything that uses the internet stops.
      - text: Only websites
        why: WhatsApp and email travel over the internet too, so they stop as well.
      - text: Only WhatsApp
        why: Websites travel over the internet too. No data means no internet.
  - prompt: A button turns green when you hover over it. Which language most likely does that?
    options:
      - text: CSS
        correct: true
        why: Yes. Colours and hover effects are about how things look, which is CSS's job.
      - text: HTML
        why: HTML puts the button on the page, but how it looks is CSS's job.
      - text: SQL
        why: SQL talks to databases. It doesn't control how pages look.
    hint: Which layer is about looks?
  - prompt: In the restaurant analogy, what is your browser?
    options:
      - text: The customer placing an order (the client)
        correct: true
        why: Exactly. The browser asks, and the server answers.
      - text: The kitchen (the server)
        why: The kitchen is the server. Your browser is the one asking.
      - text: The menu
        why: Close, but the browser is the one doing the ordering.
  - prompt: An app checks that your password is correct. Where does that usually happen?
    options:
      - text: In the back end, on a server
        correct: true
        why: Right. Checking passwords must happen where users can't tamper with it, which is the back end.
      - text: In the front end, in the browser
        why: Anything in the browser can be changed by the user, so security checks belong on the server.
      - text: In CSS
        why: CSS only controls looks.
---

Four questions about the web. Wrong answers explain why, so try again as often as you like.
