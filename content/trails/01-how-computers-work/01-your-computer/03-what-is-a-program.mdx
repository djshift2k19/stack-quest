<Analogy title="Recipe versus ingredients">
A recipe book on the shelf doesn't make dinner. A recipe is a list of steps, and the ingredients are what the steps act on. Dinner only happens when a cook **follows** the recipe **using** the ingredients.
</Analogy>

## Programs

A <Term word="program">**program**</Term> (also called an **app** or **software**) is a file full of instructions for the computer. It's the recipe.

Safari, WhatsApp, Spotify and Stack Quest itself are all programs.

The files a program works on are **data**: the ingredients. A photo is data, and the Photos app is the program that shows it. Your progress in Stack Quest (XP, badges, streak) is data, and the Stack Quest code is the program that works it out.

## Code

People don't write instructions in the computer's own language, which is just long strings of 1s and 0s. They write in a **programming language** that humans can read, such as JavaScript, which you'll learn in this course. The text they write is called <Term word="code">**code**</Term>.

Here's a tiny piece of real code. Don't worry about the details yet: just notice it reads almost like English.

```js
if (unitsFinished === unitsInModule) {
  giveBadge("Computer Whisperer");
}
```

## Running a program

**Running** (or **executing**) a program means the computer actually follows its instructions, step by step. Double-clicking an app on your Mac runs it. When you open Stack Quest in a browser, your browser runs Stack Quest's code.

<KeyIdea>
A **program** is a set of instructions (the recipe). **Data** is what it works on (the ingredients). **Code** is how humans write those instructions, and **running** a program is the computer following them.
</KeyIdea>
