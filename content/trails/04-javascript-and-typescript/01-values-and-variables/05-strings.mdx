<Analogy title="Fill in the blanks">
A birthday card might say "Happy birthday, ______!" with a blank to fill in. Template literals are text with blanks that JavaScript fills in for you.
</Analogy>

A <Term word="string">string</Term> is text, inside quote marks. You can use `"double"` or `'single'` quotes, as long as both ends match.

## Joining strings

`+` joins strings together:

```javascript
const first = "Thandi";
console.log("Hello, " + first + "!");   // Hello, Thandi!
```

Watch the spaces: `"Hello," + first` gives `Hello,Thandi` with no space, because JavaScript only adds what you give it.

## Template literals: the easier way

Use **backticks** (the key above Tab on a Mac keyboard, next to the 1) instead of quote marks, and you can put values straight inside with a dollar sign and curly brackets:

```javascript
const first = "Thandi";
const age = 24;
console.log(`${first} is ${age} years old.`);   // Thandi is 24 years old.
```

This is called a **template literal**. Most JavaScript developers use them because they're easier to read than lots of `+` signs.

## How long is a string?

Every string has a `.length`: the number of characters in it, including spaces.

```javascript
console.log("Soweto".length);   // 6
```
