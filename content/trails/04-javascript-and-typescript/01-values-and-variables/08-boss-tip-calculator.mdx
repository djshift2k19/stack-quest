    // Dinner at a restaurant in Pretoria
    const bill = 480;
    const tipPercent = 15;
    const people = 4;

    // 1. Work out the tip (15% of the bill)
    const tip = bill * tipPercent / 100;

    // 2. Work out the total (bill plus tip)
    const total = bill + tip;

    // 3. Work out what each person pays (total shared between everyone)
    const each = total / people;

    // 4. Make a message like: Tip: R72. Total: R552. Each person pays R138.
    const message = `Tip: R${tip}. Total: R${total}. Each person pays R${each}.`;

    console.log(message);

Four friends have dinner in Pretoria. The bill is R480 and they want to leave a 15% tip. Build a calculator that works out:

1. The **tip**, in a variable called `tip`
2. The **total**, bill plus tip, in `total`
3. What **each** person pays, in `each`
4. A **message** that reads exactly: `Tip: R72. Total: R552. Each person pays R138.`

Use the variables, not the numbers. If the bill changes to R600 tomorrow, only the first line should need to change. (Try it after you pass!)
