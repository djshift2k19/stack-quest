A <Term word="boolean">boolean</Term> is a value that can only be `true` or `false`: the answer to a yes-or-no question. Comparisons give you booleans:

- `>` greater than, `<` less than
- `>=` greater than **or equal to**, `<=` less than or equal to
- `===` exactly equal (the **same value** and the **same type**)
- `!==` not equal

```javascript
console.log(10 > 3);      // true
console.log(10 === 10);   // true
console.log("10" === 10); // false: one is a string, one is a number
```

## Why three equals signs?

- One `=` puts a value **into** a variable.
- Three, `===`, **compares** two values.
- There's also a two-sign `==`, which tries to convert types first, so `"10" == 10` is `true`. That causes surprising bugs, so professionals almost always use `===`.
