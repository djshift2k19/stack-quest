    // Gogo's spaza shop has a special:
    //   spend R200 or more and get R20 off.
    // basketTotal(prices) should hand back what the customer pays.
    function basketTotal(prices) {
      // 1. Add up all the prices
      let total = 0;
      for (const price of prices) {
        total = total + price;
      }

      // 2. If the total is R200 or more, take R20 off
      if (total >= 200) {
        total = total - 20;
      }

      // 3. Hand back the answer with return
      return total;
    }

    console.log(basketTotal([50, 80, 30]));
    console.log(basketTotal([120, 90]));

Gogo's spaza shop is running a special: **spend R200 or more, and get R20 off**. Write the `basketTotal` function so it hands back what the customer actually pays.

`prices` is an array of prices, like `[50, 80, 30]`. Your function needs to:

1. **Add up** all the prices
2. **Take R20 off** if the total is R200 or more
3. **Return** the answer

The checks try lots of different baskets, including the edges: exactly R200, R199 and an empty basket.
