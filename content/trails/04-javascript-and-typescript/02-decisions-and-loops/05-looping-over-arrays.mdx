You'll often want to do something with **every** item in an array. There's a loop made for that, `for...of`:

```javascript
const names = ["Lerato", "Sipho", "Naledi"];

for (const name of names) {
  console.log(`Hello, ${name}!`);
}
```

Read it as "for each `name` in `names`". The loop runs once per item, and each time, `name` holds the next one. No counter needed.

## Adding things up

A very common pattern: start a **running total** at 0 **before** the loop, then add to it **inside** the loop:

```javascript
const scores = [10, 20, 15];
let sum = 0;

for (const score of scores) {
  sum = sum + score;
}

console.log(sum);   // 45
```

The total must use `let`, because it changes each time round. And it must be created **outside** the loop. Inside, it would be reset to 0 on every run.
