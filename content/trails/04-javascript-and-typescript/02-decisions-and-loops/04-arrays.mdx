<Analogy title="A row of numbered lockers">
Picture a row of school lockers, each with a number on the door. You can open any locker by its number. The strange part: in programming, the **first** locker is number **0**.
</Analogy>

An <Term word="array">array</Term> is a list of values in order, inside square brackets, separated by commas:

```javascript
const fruit = ["mango", "litchi", "guava"];
```

## Reading items

Each item has a position number called its <Term word="index">index</Term>. Counting starts at **0**:

```javascript
console.log(fruit[0]);   // mango
console.log(fruit[2]);   // guava
console.log(fruit[3]);   // undefined: there's nothing in locker 3
```

`undefined` is JavaScript's way of saying "there's nothing here".

## Adding and counting

```javascript
fruit.push("marula");        // adds to the end
console.log(fruit.length);   // 4
```

Wait, `fruit` is a `const`, but we changed it? `const` means the variable always holds **the same array**. You can still put things in and take things out of that array, just as a labelled box can be repacked without changing its label.
