<Analogy title="Doing laps at the pool">
A swimming coach says: "Start at lap 1. Keep going while you've done fewer than 10. After each lap, count one more." That's a **loop**: the same thing, repeated, with a counter to know when to stop.
</Analogy>

A <Term word="loop">loop</Term> repeats code. The most common one is the `for` loop:

```javascript
for (let lap = 1; lap <= 10; lap++) {
  console.log(`Lap ${lap}`);
}
```

The round brackets hold three parts, separated by semicolons:

1. **Start**: `let lap = 1` makes a counter.
2. **Keep going while**: `lap <= 10` is checked before every run. When it's false, the loop stops.
3. **After each run**: `lap++` adds 1 to the counter. (`lap++` is short for `lap = lap + 1`.)

The code in the curly brackets runs once for each lap: 10 times here.

**Careful:** if the "keep going" condition never becomes false, the loop never ends. That's an **endless loop**. Stack Quest stops it after a few seconds, but in a real app it would freeze the page.
