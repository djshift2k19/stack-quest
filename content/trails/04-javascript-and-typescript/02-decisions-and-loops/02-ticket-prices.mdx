challenge:
  language: javascript
  starter: |
    // Ticket prices at the Durban aquarium:
    //   under 12: R150
    //   60 and over (pensioners): R180
    //   everyone else: R250
    function ticketPrice(age) {
      if (age < 12) {
        return 150;
      } else if (age > 60) {
        return 180;
      } else {
        return 250;
      }
    }

    console.log(ticketPrice(8));
    console.log(ticketPrice(60));
  solution: |
    // Ticket prices at the Durban aquarium:
    //   under 12: R150
    //   60 and over (pensioners): R180
    //   everyone else: R250
    function ticketPrice(age) {
      if (age < 12) {
        return 150;
      } else if (age >= 60) {
        return 180;
      } else {
        return 250;
      }
    }

    console.log(ticketPrice(8));
    console.log(ticketPrice(60));
  hints:

    - '"60 and over" includes 60 itself. Does > 60 include 60?'
    - Change age > 60 to age >= 60 on line 8.

This code is wrapped in a **function** called `ticketPrice`. You'll learn functions properly in the next module. For now, all you need to know: `ticketPrice(60)` runs the code inside with `age` set to 60, and `return` hands back the price.

A gogo turned 60 last week and was charged the full R250. Find the bug.

Bugs love to hide at the **edges**: exactly 12, exactly 60. Professional testers always check the edges, and so do the checks here.
