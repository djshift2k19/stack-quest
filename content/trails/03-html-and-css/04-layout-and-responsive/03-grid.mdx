<Analogy title="An egg box">
An egg box has a fixed number of rows and columns, and each egg drops into the next free hole. <Term word="css-grid">CSS Grid</Term> works the same way: you describe the holes, and the children drop into them in order.
</Analogy>

Flexbox lines things up in **one** direction, a row *or* a column. Grid handles **two** directions at once, rows *and* columns, which is perfect for galleries and card layouts.

```css
.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 12px;
}
```

- `display: grid` goes on the **container**, just like Flexbox.
- `grid-template-columns` describes the columns. `repeat(3, 1fr)` means "three columns, each one **fr**". `fr` is a *fraction* of the free space, so three `1fr` columns get a third each. `1fr 2fr` would make the second column twice as wide as the first.
- You don't say how many **rows**: the grid adds as many as it needs. Six photos in three columns make two rows.
- `gap` is the space between the holes, just like in Flexbox.
