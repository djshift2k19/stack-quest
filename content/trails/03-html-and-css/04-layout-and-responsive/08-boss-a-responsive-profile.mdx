  solution: |
    /* Phones first */
    body {
      font-family: Arial, sans-serif;
    }

    header {
      display: flex;
      justify-content: space-between;
      align-items: center;
    }

    nav {
      display: flex;
      gap: 16px;
    }

    .cards {
      display: grid;
      gap: 16px;
    }

    .card {
      border: 1px solid #cccccc;
      border-radius: 12px;
      padding: 12px;
    }

    img {
      max-width: 100%;
      height: auto;
    }

    /* Wider screens */
    @media (min-width: 600px) {
      .cards {
        grid-template-columns: repeat(2, 1fr);
      }
    }

This is the **Trail Boss**: everything from Trail 3 in one page. Thabo's portfolio has all its HTML. Make it **responsive**, mobile-first:

**Phones first** (outside any media query):

1. In the **header**, put the name on the left and the menu on the right
2. Put the **menu links** in a row with a gap
3. Put the **cards** in a **grid** with a gap, in **one column**
4. Make the **images** fit their cards and keep their shape

**Wider screens** (inside a media query, `min-width` of your choice up to 800px):

5. Show the cards in **two columns**

Then add any extra styling you like: colours, fonts and rounded corners. The checks look at the page at 800px wide, like a small laptop. Make your browser window narrow to see your phone layout.

Finish this, and you've built a real responsive web page from scratch. 🎉
