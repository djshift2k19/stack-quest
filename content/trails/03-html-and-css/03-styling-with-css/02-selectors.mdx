The simplest <Term word="selector">selector</Term> is just a tag name. `p` selects **every** paragraph on the page, so one rule styles them all:

```css
p {
  color: grey;
}
```

You can write as many rules as you like, one after another.

**Spelling:** CSS uses American spelling, so it's `color`, not "colour". Writing `colour: teal;` does nothing, and the browser won't tell you why.

## Your turn

Style the jazz night page:

1. Make the **h1** `teal`
2. Make **every paragraph** `18px` (use `font-size`)
3. Make the **link** `darkorange`

CSS knows about 140 colour names, like `teal`, `tomato` and `darkorange`.
