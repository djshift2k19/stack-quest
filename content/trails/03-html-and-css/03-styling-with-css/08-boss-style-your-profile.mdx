      color: #e63946;

    .card {
      background-color: white;

      border: 1px solid #a8dadc;
      border-radius: 12px;
      margin-bottom: 16px;
    }

      color: #457b9d;
    }
  hints:
    - Work through the list one rule at a time, checking the preview after each. You'll need rules for body, h1, .card and a.
    - "body needs font-family and background-color. .card needs padding (at least 16px), a border and border-radius. Change h1's and a's color."
    - "Try: body { font-family: Arial, sans-serif; background-color: #f1faee; } h1 { color: #e63946; } .card { padding: 16px; border: 1px solid #a8dadc; border-radius: 12px; margin-bottom: 16px; } a { color: #457b9d; }"
  tests:
    - name: The page uses a sans-serif font
      code: expect(getComputedStyle(document.body).fontFamily).toMatch(/sans-serif/)
    - name: The page has a background colour that isn't plain white
      code: |
        const bg = getComputedStyle(document.body).backgroundColor;
        expect(bg).not.toBe("rgba(0, 0, 0, 0)");
        expect(bg).not.toBe("rgb(255, 255, 255)");
    - name: The h1 has a colour other than black
      code: expect(getComputedStyle(document.querySelector("h1")).color).not.toBe("rgb(0, 0, 0)")

      code: |
        for (const c of document.querySelectorAll(".card")) expect(parseFloat(getComputedStyle(c).paddingTop)).toBeGreaterThan(15);

      code: |
        const [a, b] = document.querySelectorAll(".card");
        expect(b.getBoundingClientRect().top - a.getBoundingClientRect().bottom).toBeGreaterThan(0);
    - name: The link isn't the browser's default blue
      code: expect(getComputedStyle(document.querySelector("a")).color).not.toBe("rgb(0, 0, 238)")
---

Naledi's profile page works, but it looks like it's from 1995. Give it some style. You choose the colours!

1. Give the page a **sans-serif font** and a **background colour** (not plain white)
2. Give the **h1** a colour other than black
3. Make each **card** (class `card`) look like a card: at least **16px of padding**, a **border** and **rounded corners**
4. Leave **space between** the two cards (hint: margin)
5. Give the **link** a colour other than the default blue

Need colour ideas? Try `#264653`, `#2a9d8f`, `#e9c46a`, `#f4a261` and `#e76f51`, which all look good together.
