<Analogy title="Mixing paint at the hardware store">
At the paint counter, every colour has a code like "Desert Sand 0473" so it can be mixed exactly the same every time. Web colours have codes too.
</Analogy>

## Hex colours

Colour names are handy, but there are only about 140 of them. Designers use **hex codes**, which can describe over 16 million colours:

```css
h1 {
  color: #1d3557;
}
```

A hex code is a `#` and six characters. They're three pairs: how much **red**, **green** and **blue** light to mix, from `00` (none) to `ff` (full). So `#ff0000` is pure red, `#000000` is black and `#ffffff` is white. You don't need to work them out yourself. Design tools and colour pickers give you the codes, and you copy them in.

## Fonts

```css
body {
  font-family: Arial, sans-serif;
}
```

`font-family` is a **list**. The browser uses the first font it has. If it doesn't have Arial, it falls back to any `sans-serif` font (a clean font without little "feet" on the letters). Always end the list with `sans-serif` or `serif` as a safety net.

Styling `body` styles the whole page, because the elements inside **inherit** the font and text colour from the body, like children inheriting their parents' surname. (Background colours don't inherit, but you'll see the body's background behind everything anyway.)
