    <!doctype html>
    <html lang="en">
      <head>
        <meta charset="utf-8">
        <title>Contact Lerato's Hair Studio</title>
      </head>
      <body>
        <header>
          <h1>Lerato's Hair Studio</h1>
        </header>
        <main>
          <h2>Book an appointment</h2>
          <form>
            <label for="name">Your name</label>
            <input id="name" type="text" required>

            <label for="email">Your email</label>
            <input id="email" type="email" required>

            <label for="message">What would you like done?</label>
            <textarea id="message"></textarea>

            <button type="submit">Send</button>
          </form>
        </main>
        <footer>
          <p>Shop 4, Maponya Mall, Soweto</p>
        </footer>
      </body>
    </html>
  hints:
    - Build the outline first (header, main, footer), then put the form inside main. Add one field at a time, each with its own label.
    - Every input and the textarea needs an id, and a label whose for matches it. Use type="email" for the email box, and required on the name and email.
    - "Inside main: a form with label for=\"name\" + input id=\"name\" type=\"text\" required, label for=\"email\" + input id=\"email\" type=\"email\" required, label for=\"message\" + textarea id=\"message\", then <button type=\"submit\">Send</button>."

Lerato runs a hair studio in Soweto and wants a contact page that **everyone** can use. Build it from scratch:

1. A **header** with a main heading (the studio's name)
2. A **main** section containing a **form** with:
   - a **name** box (text, required)
   - an **email** box (email, required)
   - a **message** box (a `textarea`)
   - a **submit button**
3. A **footer** with the address

Every box needs its own **label**, linked with `for` and `id`.
