        <h1>Hi, I'm Sipho</h1>
        <p>I live in Gqeberha and I'm learning to build web apps.</p>
        <img src="me.jpg" alt="Sipho smiling on the beach at Summerstrand">
        <h2>Things I love</h2>
        <ul>
          <li>Rugby</li>
          <li>My gogo's cooking</li>
          <li>Learning new things</li>
        </ul>
        <h2>Find me online</h2>
        <p><a href="https://github.com">My projects on GitHub</a></p>
      </body>
    </html>
  hints:

    - "Write <h1>Hi, I'm ...</h1>, a <p>, an <img src=\"me.jpg\" alt=\"...\">, <h2>Things I love</h2>, a <ul> with three <li> items, and a link like <a href=\"https://github.com\">My projects on GitHub</a>."

Time to put it all together. Build a page **about you** (or a made-up person, if you'd rather) inside the empty body.

Your page needs:

1. **One main heading** with your name
2. **A paragraph** about you
3. **An image** with alt text that describes it (any file name)
4. **A smaller heading**, like "Things I love"
5. **A list** with at least three items
6. **A link** to a web address starting with `https://`, with words that say where it goes

There's no single right answer. Make it yours! In the next module you'll add meaning to it, and in module 3 you'll make it look good.
