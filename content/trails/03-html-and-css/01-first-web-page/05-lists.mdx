<Analogy title="A shopping list and a recipe">
A **shopping list** has bullets: the order doesn't matter, you can grab the milk before the bread. A **recipe's method** has numbers: you must boil the water *before* you pour it.
</Analogy>

## Two kinds of list

**Bulleted list** (`ul`, an "unordered list"), for when order doesn't matter:

```html
<ul>
  <li>Milk</li>
  <li>Bread</li>
  <li>Mielie meal</li>
</ul>
```

**Numbered list** (`ol`, an "ordered list"), for when order matters:

```html
<ol>
  <li>Boil the water.</li>
  <li>Stir in the mielie meal.</li>
</ol>
```

Both use `li` (list item) for each item, and **every `li` must sit inside a `ul` or an `ol`**. A list item on its own is like a shopping item written on the fridge door instead of on the list.

The browser adds the bullets or numbers for you. You never type "1." yourself. That means if you add a step in the middle, the numbers update automatically.

## Fix the bug

This rooibos recipe has two problems:

1. Its steps happen in order, but it uses a bulleted list.
2. The last step has escaped from the list.

Fix both. The preview will show numbers 1 to 4 when it's right.

<KeyIdea>
Use **`ol`** when order matters and **`ul`** when it doesn't. Every **`li`** goes inside one of them.
</KeyIdea>
