<Analogy title="A newspaper page">
A newspaper has one big headline, then smaller headings for each section, then paragraphs of text. Your eye uses the headings to jump to what you want. Web pages work the same way.
</Analogy>

## Six sizes of heading

HTML has six heading levels, from `h1` (the most important) to `h6` (the least):

```html
<h1>Recipes from home</h1>
<h2>Main meals</h2>
<h3>Curries</h3>
```

Two rules that professionals follow:

1. **One `h1` per page.** It's the page's headline.
2. **Don't skip levels.** Go from `h1` to `h2` to `h3`, like chapters and sub-chapters. Pick headings for their **meaning**, not their size. You'll change sizes later with CSS.

## Paragraphs

Each block of text goes in its own `p` element. The browser adds a little space between paragraphs automatically.

One surprise: pressing Enter inside your HTML **doesn't** start a new line on the page. The browser squashes all spaces and line breaks into a single space. To start a new paragraph, start a new `p`.
