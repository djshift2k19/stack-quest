Developers rarely open projects through menus. Instead they `cd` into the folder and type:

```
code .
```

The single dot `.` means **"this folder, right here"**, just as `..` means "the folder above".

## Setting it up on your real Mac (one time)

The `code` command isn't switched on by default:

1. Open VS Code.
2. Press **⌘⇧P** to open the Command Palette.
3. Type `shell command` and choose **"Shell Command: Install 'code' command in PATH"**.
4. Close and reopen your Terminal app.

After that, `code .` works from any folder.

Practise below first. The practice terminal pretends to open VS Code.
