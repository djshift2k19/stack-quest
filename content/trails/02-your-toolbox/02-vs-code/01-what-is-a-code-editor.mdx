<Analogy title="A kitchen versus a camping stove">
You *can* cook a meal on a camping stove. But a proper kitchen has the right knives within reach, a timer, labelled spices and a sink right there. A <Term word="code-editor">code editor</Term> is a proper kitchen for code.
</Analogy>

Code is just text, so you could write it in TextEdit. But a code editor helps you in ways that matter every minute:

1. **Colours (syntax highlighting).** Different parts of the code get different colours, so mistakes stand out. A missing quote mark turns the rest of the line the wrong colour.
2. **Error squiggles.** Wavy red lines under problems as you type, before you even run the code.
3. **Auto-complete.** Start typing a name and the editor suggests the rest. That's fewer typos and less to remember.
4. **The whole project in one window.** All your files in a sidebar, a built-in terminal at the bottom, and Git changes shown in colour.
5. **<Term word="extension">Extensions</Term>.** Free add-ons for almost anything: new languages, formatting, spell-checking.

## VS Code

**Visual Studio Code** ("VS Code") is free, made by Microsoft, and used by most web developers. You're probably using it right now to work on Stack Quest. Inside Stack Quest, the code boxes use a much smaller editor (CodeMirror) with the same colour-and-help idea.

<KeyIdea>
A **code editor** helps you write code with colours, error squiggles, auto-complete, a project sidebar, a built-in terminal and extensions. **VS Code** is the most popular one, and it's free.
</KeyIdea>
