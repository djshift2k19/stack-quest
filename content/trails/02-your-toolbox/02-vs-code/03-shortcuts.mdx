<Analogy title="Driving without looking at the gear stick">
New drivers look down to change gear. Experienced drivers don't, so their eyes stay on the road. <Term word="shortcut">Keyboard shortcuts</Term> keep your eyes (and brain) on the code.
</Analogy>

On a Mac, **⌘** is the Command key, **⌥** is Option, **⇧** is Shift and **⌃** is Control.

## The essential ten

- **⌘S**: save. Do it constantly.
- **⌘Z** / **⌘⇧Z**: undo / redo.
- **⌘P**: open any file by typing part of its name. **The single biggest time-saver.**
- **⌘⇧P**: the Command Palette, which can do anything in VS Code by searching for it.
- **⌘F**: find in this file. **⌘⇧F** finds in **every** file.
- **⌘/**: turn the current line into a comment (a note the computer ignores), or back.
- **⌥↑** / **⌥↓**: move the current line up or down.
- **⌥⇧↓**: copy the current line below itself.
- **⌘D**: select the next copy of the selected word. Press it repeatedly, then type to change them all at once.
- **⌃`**: show or hide the built-in terminal.

## Don't try to learn them all today

Pick **two**, say ⌘P and ⌘S, and use them all week. Then add two more. Within a month they'll be automatic.

**Try now in VS Code:** press **⌘P**, type `glossary` and press **Enter**. You just opened a file without touching the mouse.

<KeyIdea>
Learn shortcuts two at a time. Start with **⌘P** (open any file) and **⌘S** (save), then add **⌘⇧P** (do anything) and **⌘/** (comment).
</KeyIdea>
