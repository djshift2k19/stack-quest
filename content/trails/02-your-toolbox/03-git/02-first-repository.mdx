`git init` switches Git on for a folder, turning it into a repository. You only do it **once** per project.

`git status` is the command you'll type most. It answers: "What's changed? What's ready to save?" When in doubt, run `git status`.

**Try this first, for fun:** before `git init`, type `git status`. Git complains `fatal: not a git repository`, because it isn't switched on in that folder yet. "fatal" sounds scary, but it just means "I can't do that". Read the translator's explanation, then carry on with the tasks.
