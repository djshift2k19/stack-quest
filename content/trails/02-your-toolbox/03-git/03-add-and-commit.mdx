Saving a snapshot takes **two steps**:

1. **`git add <file>`**: choose what goes in the snapshot. This puts it in the <Term word="staging-area">staging area</Term>.
2. **`git commit -m "message"`**: take the snapshot, with a message describing it.

<Analogy title="Packing a box to post">
`git add` puts items in the box. `git commit` seals it, labels it and puts it on the shelf with the date. You can pack items one at a time and seal the box when you're ready.
</Analogy>

Git is already switched on in this folder, and there's a recipe file waiting. Run `git status` after each step to watch things change.
